# 微光共鸣 · PIXEL TAMER
### 像素怪物养成 RPG —— 基础框架设计文档 v0.1

> 一句话定位：**一款 320×224 掌机分辨率的回合制怪物收集游戏，把「属性克制」换成「节拍与共鸣」的童年手感。**
> 交付物：`index.html` —— 单文件、无外部素材、双击即玩的完整原型（战斗 / 捕捉 / 养成 / 4 张地图 / 3 个原创小玩法 / 图鉴 / 存档 / 8-bit 音效）。

---

## 1. 设计目标与边界

| 维度 | 目标 | 刻意不做 |
|---|---|---|
| 操作 | 方向键 + 一个确认键，全部可单手完成 | 无摇杆、无连招、无实时战斗 |
| 单局时长 | 遭遇战 20～40 秒，主线 20～30 分钟 | 不做开放世界、不做联网 |
| 数值 | 玩家无需查表，凭直觉能算清 | 不做 6 维努力值/个性/蛋招 |
| 情绪 | "再打一只就睡"的掌机节奏 | 不做长剧情演出 |
| 美术 | 16×16 逻辑网格 + 全程序化绘制 | 不引入外部图片素材 |

**核心取舍**：把所有复杂度集中在"一拍一策"的决策上——用哪个属性、第几拍共鸣、什么时候扔球。其余系统保持极薄。

## 2. 像素美术风格规范

### 2.1 分辨率与网格

| 项目 | 规格 |
|---|---|
| 逻辑分辨率 | 320 × 224（GB/GBC 尺寸比例的现代变体） |
| 显示倍率 | 整数 2× = 640 × 448（禁止 1.5× 等非整数缩放） |
| 图块（Tile） | 16 × 16 px，地图 20 × 14 格 = 满屏不滚动 |
| 角色 / 怪物 | 16 × 16 px 逻辑网格，战斗中以 6× 放大（96 px） |
| 渲染 | `image-rendering: pixelated` + `imageSmoothingEnabled = false` |
| 额外滤镜 | 全屏扫描线（1px 暗线 / 3px 间隔，乘算 55% 不透明度） |

### 2.2 调色板（12 色主色板 + 每只怪物 4 色皮肤）

| 用途 | 色值 | 说明 |
|---|---|---|
| 深描边 | `#20242c` | 所有 UI 面板与角色描边，唯一"黑" |
| 纸面 | `#f2f4f7` | 对话框底、卡片底 |
| 草地主色 | `#7ec46b` | 明度最高的大面积色 |
| 草地点缀 | `#6cb35c` / `#95d382` | 抖动噪点，2–3 px 一颗 |
| 小径 | `#e0cba2` / `#cbb287` | 土黄通路 |
| 水面 | `#3f7fd0` / `#6fb3e8` | 高光随 460ms 周期横移 |
| 树冠 | `#2f7a44` / `#245c34` | 双层色，上浅下深 |
| 岩石 | `#544c42` / `#6b6155` | 洞窟墙体 |
| 强调色 | `#e0603a`（火/主按钮） | 唯一暖色高饱和 |
| 冷强调 | `#5b8fd0` | 水系 / 次要按钮 |
| 成功 | `#5ec46a` | HP 条、节拍甜区 |
| 警示 | `#e8b530` | 电量灯、Perfect 判定字 |

**规则**：一张贴图最多 4 个色阶；阴影不用半透明黑，而用同色系更深一级（本作地面阴影例外，用 28% 黑）。

### 2.3 造型语言

- **圆胖剪影**：身体用"逐行宽度表"绘制，最大宽度 12 px，保证 2 px 安全边。
- **统一配件位**：每只怪只有 3 个可变件 —— 头顶件（耳/芽/鳍/角）、侧挂件（尾/翅/岩甲/闪电）、眼睛（2×2 深色 + 1 px 高光）。
- **每族一种轮廓**：火=尾焰外扩，水=鳍尾下垂，草=头顶双芽，电=尖角+锯齿尾，岩=两侧岩甲，风=双侧薄翅。
- **进化 = 换色 + 放大 + 加冠**：同一套几何组件重绘为更大宽度表并加金色冠，玩家能一眼认出"这是我那只长大了"。
- **禁止描边粗细变化**：全图 1 px 描边，缩放前不抗锯齿。

### 2.4 动画帧

| 对象 | 帧数 | 频率 |
|---|---|---|
| 主角行走 | 2 帧（身体上下 1 px 抖动） | 110ms / 帧 |
| NPC 待机 | 2 帧（呼吸浮动） | 420ms / 帧 |
| 水面 | 连续（正弦相位） | 460ms 周期 |
| 受击反馈 | 亮度闪烁 2.6× + 饱和度 40% | 180ms 衰减 |
| HP / EXP 条 | CSS width 过渡 | 280–300ms |

### 2.5 UI 规范

- 面板：3px 实描边 + 5px 硬投影（`box-shadow: 0 5px 0`），无圆角超过 5px 的"软"面板。
- 字号：正文 13px，标签 11–12px，数值/PP 用等宽字体（`ui-monospace`）。
- 战斗按钮：两行 4 列网格，移动端 44px 以上触控热区。
- 属性标签：胶囊形，底色直接取该属性的主色（玩家不用读字也能认属性）。

## 3. 核心回合战斗系统

### 3.1 属性与克制（六属性，只有 6 条关系）

| 攻 ↓ / 守 → | 火 | 水 | 草 | 电 | 岩 | 风 |
|---|---|---|---|---|---|---|
| **火** | — | ½ | **2** | — | ½ | — |
| **水** | **2** | — | ½ | ½ | **2** | — |
| **草** | ½ | **2** | — | — | — | ½ |
| **电** | — | **2** | ½ | — | ½ | — |
| **岩** | — | — | ½ | **2** | — | — |
| **风** | — | — | **2** | — | ½ | — |

> 设计意图：**每个属性最多 2 个弱点、1 个免疫级别的诱导**，玩家可以口算；同时"火↔水↔草"三环闭环 + "电/岩/风"三角，避免原作 18 属性的记忆负担。

### 3.2 伤害公式

```
HP 上限 = ⌊种族HP × 2 × Lv / 100⌋ + Lv + 10
攻击/防御/速度 = ⌊种族值 × 2 × Lv / 100⌋ + 5

基础伤害 = ⌊((2 × Lv / 5 + 2) × 威力 × 攻 / 防) / 50⌋ + 2
最终伤害 = ⌊基础伤害 × 克制倍率 × 共鸣倍率 × 会心倍率 × 随机(0.86 ~ 1.00)⌋
会心：6.25% 概率 ×1.5
```

- 无命中率判定（全部必中），减少一层随机，胜负更可读。
- 伤害最少 1，避免高防怪互磨到死。
- 速度只决定出手顺序，同速时玩家先手。

### 3.3 回合流程

```
玩家选择（招式 / 共鸣球 / 药水 / 逃跑 / 共鸣说明）
   ↓ 速度比较（逃跑、扔球为"先制动作"，不比较速度）
我方行动 → 敌方是否倒下? → 是: 换下一只 / 结算
   ↓（敌方未倒）
敌方行动（AI：按克制期望 × 随机权重选招）
   ↓ 我方是否倒下? → 是: 自动换上下一只存活伙伴 / 全灭则回镇
回合结束
```

**AI 策略**：对每个可用招式计算 `克制倍率 × (0.7 + rand×0.6)` 取最高。既会打弱点，又不会每次都打出最优解。

### 3.4 战斗结算

| 项目 | 数值 |
|---|---|
| 经验 | `敌方等级 × 9 + 22` |
| 升级需求 | `当前等级 × 13 + 18` |
| 升级奖励 | 全属性重算，HP 补足增量 |
| 学招 | 达到等级自动学会；满 4 招则替换第 1 招 |
| 进化 | 初始三只 16 级进化，种族值 +45% 左右 |
| 捕获后 | 羁绊重置为 10，等级与 HP 保留 |

## 4. 捕捉与养成

### 4.1 捕捉公式

```
捕获率 = clamp(种族捕获率 × (1 − 0.62 × 敌方HP/上限) × 节拍倍率 × 1.1, 0.06, 0.95)
```

| 种族捕获率 | 对象 | 满血满判 | 1HP 完美判 |
|---|---|---|---|
| 0.42 | 初始三只 | 46% | 88% |
| 0.36 | 噼啪 / 呼噜 | 41% | 79% |
| 0.34 | 石砾 | 39% | 75% |
| 0.16 | 进化形态 | 19% | 33% |

### 4.2 节拍判定表（原创，见 §5.2）

| 判定 | 距甜区中心 | 倍率 | 提示字 |
|---|---|---|---|
| PERFECT | ≤ 甜区半宽 20% | ×1.9 | 金色 |
| GOOD | ≤ 50% | ×1.45 | 绿色 |
| OK | ≤ 100%（在甜区内） | ×1.15 | 白色 |
| MISS | 甜区外 | ×0.65 | 红色 |

### 4.3 羁绊（Bond）

| 数值 | 获取 | 效果 |
|---|---|---|
| 0–100 | 胜利 +2 / 满判篝火 +2.2×共鸣度 | **≥60 时，共鸣链需求从 3 拍降为 2 拍** |

这是全作唯一的"隐藏成长"：不靠喂食、不靠道具，只靠一起打和一起坐篝火。

## 5. 三个原创特色玩法

### 5.1 共鸣链（Resonance Chain）— 战斗层

**动机**：原作战斗里"换招"几乎没有代价，最优解是永远点最克制的那一招。共鸣链让**连续性是资源**。

| 规则 | 说明 |
|---|---|
| 蓄力 | 连续使用**同属性**招式，「链」+1（属性一换，链重置为 1） |
| 触发 | 链达到 3（羁绊 ≥60 时为 2）→ 该次攻击变为**共鸣技** |
| 效果 | 伤害 ×1.6，**且不消耗 PP** |
| 代价 | 触发后链清零，必须重新蓄 |
| 中间档 | 链 2 时伤害 ×1.1（让"差一拍"也有意义） |

**策略张力**：敌方是水属性，你的草招打两次就该共鸣了 —— 但中途对方换了岩属性怪，你要不要为了保链继续打效果不好的同属性招？UI 上用 3 颗圆点实时显示，不占字数。

### 5.2 节拍捕捉（Rhythm Capture）— 操作层

**动机**：原作扔球是一个"概率确认键"，玩家没有参与感。这里把"扔球"变成一个 1 拍的节奏判定。

| 规则 | 说明 |
|---|---|
| 表现 | 一根指针在轨道上来回摆动，绿色甜区随机落在轨道上 |
| 输入 | 一次空格 / 一次点击，按下的瞬间判定 |
| 反馈 | 判定字 + 甜区变暗 + 三下"摇晃"演出 |
| 手感 | 指针速度随敌方等级微增；开局 320ms 输入保护，避免"顺手按空" |

**为什么不做 QTE 连打**：单次判定更接近"握着手柄屏住呼吸"的掌机记忆，也照顾单手操作。

### 5.3 篝火共鸣（Campfire Resonance）— 营地层

**动机**：治疗不该是"走回城镇找护士"。把回血变成一件有节奏感的小事。

| 规则 | 说明 |
|---|---|
| 入口 | 镇上「篝火守」NPC，或菜单里的「篝火共鸣」 |
| 玩法 | 5 拍判定，甜区逐拍随机；PERFECT=2 分 / GOOD=1.4 / OK=1 / MISS=0 |
| 产出 | 全队回复 `6% × 共鸣度` 的体力（上限 62%），羁绊 +`共鸣度 × 2.2` |
| 失败无惩罚 | 打得差只是回得少，不会掉血 |

**闭环**：篝火 → 羁绊升高 → 共鸣链从 3 拍变 2 拍 → 战斗更快 → 更敢去洞窟练级 → 回来再坐篝火。

> 三个玩法共用同一套"节拍判定"内核（一个函数），美术与音效复用，学习成本只付一次。

## 6. 主线冒险地图脉络

### 6.1 五区结构（原型实现前 4 区）

| # | 区域 | 功能 | 野生分布 | 关键事件 |
|---|---|---|---|---|
| 1 | **微光镇** | 安全区 / 教学 / 篝火 | 无 | 选初始伙伴、篝火守教节拍、旅人提示共鸣 |
| 2 | **苔原小径** | 第一段草丛迷宫 | 芽芽/噼啪/呼噜/露滴 Lv3–6 | 采集者教"残血回镇"、摆渡人指向湖 |
| 3 | **风蚀洞窟** | 岩系关卡 + Boss | 石砾/噼啪/呼噜/芽芽 Lv8–11 | 守塔人二连战（石砾 Lv13 → 呼噜 Lv14） |
| 4 | **星落湖畔** | 水域 / 共鸣石解谜 / 高阶练级 | 露滴/呼噜/芽芽/噼啪 Lv10–14 | 共鸣石三拍挑战、岛上拾荒者给补给 |
| 5 | *共鸣之塔（待做）* | 终局 / 塔层挑战 | 全属性 Lv18+ | 五层塔，每层限制属性 |

### 6.2 动线

```
微光镇（选伙伴）
   │  南出口
苔原小径 ── 草丛遭遇（教学：属性克制）
   │  ├─ 南出口 → 风蚀洞窟（迷宫 → 守塔人 2 连战 → 结局字）
   │  └─ 东出口 → 星落湖畔（共鸣石 → 湖心岛 → 补给）
   │
（待扩展）共鸣之塔
```

- 单区 20×14 一屏，**不滚动**，天然的"掌机一屏记忆"。
- 每区只有一个出口方向，避免迷路；洞窟内部用墙体做 3 段折返。
- 遇敌：踩到草丛/洞窟地面时 24% 概率，且**至少间隔 4 步**，避免连遇。

## 7. 与原作的差异化清单

| 原作常见设定 | 本作处理 |
|---|---|
| 18 属性、双属性 | **6 单属性**，克制表 6 行可背 |
| 精灵球 / 状态异常 / 携带道具 | 只保留「共鸣球」，无异常状态，无携带物 |
| 个体值 / 努力值 / 性格 | 全部删除，同种同级的怪完全一致 |
| 进化石 / 亲密度 / 交换进化 | **统一 16 级进化**，规则可预期 |
| 招式 PP + 命中率 | 保留 PP，**取消命中率**（必中） |
| 战斗无节奏感 | **共鸣链**：连续同属性 = 资源 |
| 扔球靠概率 | **节拍捕捉**：玩家的一次判定直接改倍率 |
| 回血靠护士/药水 | **篝火共鸣**：小游戏回血 + 长羁绊 |

## 8. v0.2 增量：五个新系统

### 8.1 存档与继续旅程

| 项目 | 规则 |
|---|---|
| 存储 | `localStorage['pixel-tamer.v1']`，单个 JSON（约 700 字节起） |
| 时机 | **全自动**：换图、战斗结算、捕获、篝火、碎石；菜单另有手动「保存」 |
| 内容 | 地图 + 坐标 + 队伍 + 寄存 + 道具 + flags + 图鉴 + 静音 |
| 读档 | 标题页出现「继续旅程 · 区域 · 队伍数 · 时间」按钮 |
| 容错 | 空队伍不写盘；`file://` 下 localStorage 被禁也不崩，静默降级为不存档 |

### 8.2 8-bit 音效（零素材）

- WebAudio `square / triangle / sawtooth` 振荡器 + 指数包络，全部实时合成，**没有一个音频文件**。
- 首次点击 / 按键时才 `AudioContext`（浏览器策略），之后常驻。
- 事件音：遭遇、命中、会心、共鸣、倒地、升级、捕获、逃跑、回血、存档、碎石。
- 节拍判定四档各有音高：PERFECT 双音上行、GOOD 880Hz、OK 660Hz、MISS 下滑锯齿。
- 静音开关在 HUD 右上角，状态写进存档。

### 8.3 图鉴与生态笔记

| 项目 | 规则 |
|---|---|
| 入口 | 菜单 → 图鉴页（4 列网格，9 格） |
| 三态 | 未遇见 = `???`；见过未捕 = 名字 + 灰蒙剪影；已捕获 = 全彩 + 笔记 |
| 笔记 | 每只一句习性描述（风味），点格子查看 |
| 全局被动 | 每捕获 1 种：**捕捉率 +4%**、**篝火回复上限 +2%**（叠乘 / 叠加上限） |

> 这样"收集"不只是填格子，而是直接让捕捉与续航变强 —— 一个可感知的正反馈。

### 8.4 战斗换人

- 战斗指令行新增「换人」，点开显示待命伙伴（名字 / 等级 / 血量）+ 返回。
- 换人**消耗一回合**：敌方立刻行动；同时共鸣链清零（保住"连续性即资源"的规则）。
- 用来处理属性不利对位，也让"多养几只"有意义。

### 8.5 星落湖畔与共鸣石

| 项目 | 规则 |
|---|---|
| 位置 | 苔原小径东侧出口 |
| 障碍 | 共鸣石（tile `o`）挡在通往湖心岛的唯一窄桥上 |
| 解法 | 面朝石头按交互 → **3 拍挑战，命中 ≥2 拍**才碎 |
| 奖励 | 岛上拾荒者给 3 个共鸣球 + 2 瓶药水（一次性） |
| 失败 | 纹路变暗，可立刻重试，无惩罚 |
| 高阶区 | 湖畔草丛 Lv10–14，是全作最好的练级场 |

这就是把"节拍"从战斗里搬进地图的第一块砖：**世界本身也需要节奏**。

## 10. v0.3 增量：终局塔 + 队伍管理 + 细节修补

### 10.1 共鸣之塔（终局玩法）

击败风蚀洞窟的守塔人后，与其对话即可踏入塔门（`cave → tower`）。塔为单屏 20×14 地图，五层共用同一张图，塔心的「塔中回响」NPC 按当前楼层发起试炼。

| 层 | 名称 | 对手 | 禁制 | 通关奖励 |
|---|---|---|---|---|
| 1 | 试音 | 石砾 Lv13 | **3 回合内取胜** | ◈60 · 球×2 |
| 2 | 禁焰 | 芽芽 Lv14 | **禁用火属性招式** | ◈70 · 药×2 |
| 3 | 逐流 | 澜波兽 Lv16 | **4 回合内取胜** | ◈80 · 球×3 |
| 4 | 静默 | 呼噜 Lv15 → 噼啪 Lv15 | **禁电 + 共鸣链封印** | ◈100 · 铃×1 |
| 5 | 终曲 | 炽炭兽/澜波兽/藤冠兽 Lv18 | 无（三连战） | ◈200 · 球×5 · 药×3 · 铃×1 |

- **回合上限**按整层累计（多对手层跨对手计数）；我方在最后一回合击倒对手算胜利，不判负。
- **属性禁用**在指令面板置灰并标注「本层禁用」；**共鸣封印**时共鸣链圆点熄灭、`useMove` 不进链。
- 塔内**禁止扔球与逃跑**（视同训练师战）；战斗指令新增「共鸣」按钮，随时查看当前层的规则与剩余回合。
- 失败送回微光镇、满血恢复，**楼层进度保留**，可原层重试；通关后 `towerClear` 置位、楼层归 1，可重复刷塔。
- 进度存于 `flags.towerFloor / towerClear`，随既有存档结构自动持久化，旧存档无此字段时默认第 1 层。

### 10.2 队伍与寄存箱管理

菜单标签由 2 页扩为 3 页：**队伍 / 寄存 / 图鉴**。

- 队伍、寄存两页点任意伙伴展开详情卡：属性、攻防速、经验、`当前/升级需求`、四招及剩余 PP。
- 详情卡内操作：**↑上移 / ↓下移** 调整出战顺序（首只存活者为战斗首发）、**存入寄存箱 / 取出到队伍**（队伍 1–6 只，寄存箱不限）。
- 倒下的伙伴在详情卡内可直接 **摇复苏铃**；取出寄存箱中倒下的伙伴时以 20% 体力唤醒，避免死循环。
- 战斗首发顺序与 `newMon` 生成逻辑不变，排序只影响 `party` 数组顺序。

## 11. v0.4 增量：战斗深度 + 探索 + 演出 + 收集

> 针对"太单调"的一次大升级，四个方向各加一批实打实的系统。

### 11.1 状态异常与天气（战斗深度）

**状态异常**（单目标最多同时 1 个，新异常覆盖旧异常，`STATUS` 表）：

| 状态 | 来源 | 效果 |
|---|---|---|
| 灼烧 | 火星/烈焰（20%/40%） | 每回合掉 8% 上限体力，攻击 ×0.8 |
| 浸湿 | 水枪/潮涌（20%/35%） | 速度 ×0.7 |
| 麻痹 | 电击/雷鸣（20%/35%） | 速度 ×0.5，25% 概率跳过行动 |
| 束缚 | 藤鞭（30%） | 每回合掉 6%，50% 概率跳过 |
| 硬化 | 碎石（35%） | 防御 ×1.5（自身增益） |
| 畏缩 | 旋风（25%） | 本回合无法行动，回合结束解除 |

**天气**（战斗开场 40% 概率触发，`WEATHER` 表）：烈日（火×1.5 水×0.5）、雨天（水×1.5 火×0.5）、疾风（风×1.3 + 全场速度 +15%）。敌方 AI 会感知天气选招。

**伤害公式升级**：改用有效攻防速（`effStats` 叠加词条 + 状态 + 天气），克制倍率再乘天气修正。

### 11.2 Boss 机制（守塔人 / 塔终曲）

- **回血**：训练师战对手血量 <40% 时一次性回复 30%（每只一次）。
- **狂暴**：塔内对手血量 <20% 时进入第二形态，攻击 ×1.25。

### 11.3 随机词条（收集深度）

同种怪不再完全一致——新生成野生/初始怪有 40% 概率带一个词条（`TRAITS` 表），影响攻防速/血量/会心率；进化形态词条池略强。词条随怪存进存档，升级/进化时保留。

### 11.4 图鉴被动「习性洞察」（收集深度）

捕获某族后解锁具体被动（`DEX_PASSIVES`，取已捕获族里的最优效果）：

| 捕获 | 被动 | 效果 |
|---|---|---|
| 芽芽 | 藤蔓庇护 | 遇敌率 −20% |
| 噼啪 | 静电感应 | 逃跑必定成功 |
| 呼噜 | 顺风而行 | 捕捉率 +8% |
| 石砾 | 岩皮共鸣 | 篝火回复上限 +4% |
| 露滴 | 潮汐节律 | 战斗碎晶掉落 +30% |
| 炭仔 | 炉火羁绊 | 升级所需经验 −10% |

### 11.5 随机事件与隐藏探索（探索深度）

- **随机事件**：踩草丛约 6% 概率触发（不占遇敌冷却），三种——救助受伤伙伴（可能得球/碎晶）、落灰宝箱（药水/球/铃）、神秘商人（30 碎晶换复苏铃）。
- **隐藏拾取**：洞窟暗角藏着复苏铃、石缝卡着 50 碎晶、湖岸芦苇藏着 4 个球——看不见、不挡路，踩到即触发。
- **支线任务**：货郎委托（捕获 3 种）、旅人心愿（带草属性伙伴），完成后给奖励并记入成就。

### 11.6 BGM 与打击演出（演出深度）

- **BGM**：WebAudio 实时合成三首循环旋律（探索 112BPM / 战斗 150BPM / 篝火 88BPM），随场景自动切换，静音联动。
- **打击演出**：伤害数字飘字、高伤屏幕震动、会心金色大字。
- **状态可视化**：天气横幅、敌我卡片上的词条/状态彩色标签，一眼看清战况。

### 11.7 成就系统

`ACHIEVEMENTS` 表：首战、十战、捕获 3 种、全图鉴、通关塔、羁绊满 100、见证进化、完成支线——达成即弹提示并存档。
